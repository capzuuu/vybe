# Vybe Frontend (React + Vite)

## Setup & Running

```powershell
cd d:\vybe\frontend

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Features
- **React 18 & Vite**: Fast HMR and lightweight build.
- **TypeScript**: Full static type checking.
- **Vite Proxy**: Transparently proxies `/api` requests to backend on port 8000.
- **Lucide Icons**: Clean, modern iconography.
